# 斗地主 · 午夜牌桌

入口 `/games/doudizhu/`。与飞行棋共用服务器、账号 Cookie、个人战绩和游戏大厅，前端无需构建、无需新增依赖。

## 开局

- **单人练习**：一位真人加两位人机，直接发牌。
- **创建好友房**：房主、一个朋友空位、一位人机。复制六位房间码或邀请链接给朋友，对方准备后由房主开局。
- **三位真人**：房主点人机座位的「给朋友腾座」，第三位真人用同一房间码加入。
- 空位默认在开局时自动补同难度人机；可以关闭自动补位，等三位玩家都到齐。
- 对局结束后，每位真人点击「再来一局」；全部准备后自动开始下一局。房主也可以回到房间更改难度与座位。

## 人机

| 等级 | 机制 |
| --- | --- |
| 简单 | 根据大牌与炸弹叫分；优先顺手、较小的合法牌型，偶尔保留出牌机会，适合陪练。 |
| 困难 | 在点数计数上搜索拆牌方案，保留大牌和炸弹；对手余牌少时优先拦截，农民不会随意压队友。 |
| 地狱 | 在困难策略上，根据自己的手牌、公开底牌、已出牌和各家牌数，抽样可能的对手手牌并进行有限步数推演。思考有节点与时间预算。 |

三档策略的输入都是 `botView()` 公开视角，包含本人手牌；**不包含真实对手手牌与洗牌种子**。提示也只使用当前玩家可见的信息。

## 规则

54 张牌，17/17/17 张手牌加 3 张底牌。依次叫 1、2、3 分，叫分必须抬高，3 分立即确定地主；全不叫则重新洗牌发牌并轮换首叫座位。

支持单张、对子、三张、三带一、三带一对、顺子、连对、飞机（不带／带单／带对）、四带二、四带两对、炸弹、王炸。顺子至少五张，连对至少三对，飞机至少两组三张；这些连续牌型的主体不含 2 和王。

本桌对容易有分歧的规则作统一约定：飞机单牌翅膀允许对子，但不能带三张同点数或使用机身点数；对翅膀使用不同点数的对子。四带二允许带一对；四带两对使用两种不同点数的对子。三张机身从四张同点数的手牌中抽取也合法，剩下一张保留在手牌中。

炸弹与王炸每次让倍率翻倍。地主胜且农民两家均没出过牌是春天；农民胜且地主只出过一手是反春天，均再翻倍。积分为叫分 × 最终倍率，地主得失两份、农民各一份，三方积分之和为零。农民共享胜负，两个登录账号均记入胜场。积分仅为对局娱乐结算。

## 联机与恢复

- 独立协议 `/ws/doudizhu`，不会进入飞行棋的消息处理和房间管理。
- 服务器洗牌、校验轮次、校验所属手牌、识别牌型和结算。每位客户端仅收到自己的手牌，底牌在地主确定后公开，对局结束才揭示余牌。
- 叫分 15 秒、出牌 30 秒；超时自动代走一手。真人可以开启／收回托管。
- 断线 2.5 秒后临时由人机接管；重连恢复同一局并收回临时托管。手动开启的托管会继续保留。
- 恢复凭据使用 192 位随机 token，保存在当前标签页的 `sessionStorage`。重连只发送 `hello` 同步身份和牌局，不重放建房、加入、准备、出牌操作。
- 同一玩家只保留一条连接，新连接接回牌桌时旧连接停止自动重连。已登录 token 绑定对应账号，不能被匿名连接恢复。一个账号在同房间不能占两个座位。
- 游客开房后登录会重新握手接回原座位并绑定后续战绩；退出账号只解除当前玩家的战绩绑定，牌局与手牌继续保留。
- 建房 `requestId` 在 60 秒内幂等；错误房间码不会销毁已有牌局。无人连接的空闲房间会清理。

## 视觉与操作

深绿牌桌、奶油纸张牌面、金色细节、对称花色点阵与人物牌插画。发牌逐张飞入，地主底牌翻面，选牌抬起，出牌飞入对应桌面位置；顺子、连对、飞机有组合提示，炸弹／王炸有冲击效果，胜利有纸屑动画。支持减少动态效果的系统偏好。

支持点击或划过多张选牌、按点数／牌型理牌、轮换提示、记牌器、快捷表情、托管、音效开关与桌面全屏。`H` 提示、`Enter` 出牌、空格不出、`Esc` 清除选择；按钮聚焦时遵循按钮的键盘行为。手机竖屏与横屏均保留手牌和操作区。

背景与插画由用户配置的第三方 `gpt-image-2.5` 生成。提示词在 `tools/doudizhu-art.jsonl`，原始人物图在 `assets/card-characters.png`，通过 `python tools/prepare-doudizhu-art.py` 生成六张 WebP 插画。牌的点数、花色、边框和交互是原生 HTML/CSS/SVG，音效由 Web Audio 合成，离线素材不依赖外部资源地址。

## 定向验证

```sh
npm run test:doudizhu
npm run test:flight-room
node backend/test-assets.mjs
```

斗地主测试独立启动随机端口的 WebSocket 服务；战绩测试使用临时 SQLite 数据库，不改动玩家账号数据库。

浏览器检查清单：桌面与手机首屏、三档切换、昵称、单人练习、好友房、准备与开局、叫分、20 张地主手牌、点击／拖动选择、理牌、提示、出牌／不出、超时、记牌器、表情、托管、结算与双方再开局；检查动画中间帧及结束帧、长牌型与手机满手牌的遮挡、断线重连和重复连接。

可选的浏览器验收脚本是 `tools/doudizhu-browser-check.cjs`，传入已安装的 Playwright 模块路径即可运行。它检查特殊动画、手机长牌型角标是否被遮挡，以及真实账号接口下的登录／退出／战绩更新；账号测试服务使用独立临时数据库并自动清理。`--visual-only` 只检查画面，`--dense-only` 只检查长牌型布局。
