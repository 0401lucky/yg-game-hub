# 合成大西瓜 · 软软果园

入口为 `/games/watermelon/`，大厅共用账号。引擎与水果素材迁自本地兑换码项目；页面改为本仓库的原生 TypeScript + Vite 多页面结构，无 React、Next.js 或原项目积分服务依赖。

相同水果相碰会合成下一等级，直到大西瓜。实际软体轮廓参与碰撞与承重；投放有冷却，水果持续堆过警戒线才会结束。鼠标或触屏轻点投放、拖动瞄准，键盘左右键瞄准、空格投放、P 暂停。后台自动暂停。

- 自由练习支持 U 撤回上一颗水果，本机保存进度、最高分与最近收获。
- 战绩挑战关闭撤回。服务器发放种子，以同一份 TS 引擎复算投放记录，按每段最多 240 tick、32 次投放处理；客户端分数与物理快照不参与计分。
- 游客能直接挑战，登录后可接管未完成的游客进度。账号已有进行中的挑战时保留账号那一局。
- 刷新恢复时暂停，保留尚未同步的投放；请求重试与结算幂等。在途同步完成后，再提交剩余输入及最终 tick，避免提前结算漏分。
- 账号成绩复用 `matches`、`match_players`，附加 `watermelon_results` 保存分数、最高水果与投放次数。表由已有账号初始化流程自动创建，胜场表示合成了大西瓜。
- 挑战进度在服务器内存中保留 24 小时；服务器重启后未结算挑战需重开，已保存账号成绩仍在 SQLite 中。

HTTP 使用 `/api/watermelon/status`、`start`、`checkpoint`、`finish`。挑战计入运营概况和每日开局、结算统计；自由练习在本机运行。

定向验证：`node --test tests/node/watermelon.test.ts`，以及 `npx playwright test tests/e2e/watermelon.spec.ts`。上线门禁沿用仓库的类型检查、构建、Node 与 Playwright 测试。
