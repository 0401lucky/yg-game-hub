# 扫雷 · 林间探险

入口为 `/games/minesweeper/`，已注册到游戏大厅。游客可直接玩，登录后复用大厅账号保存胜负和最佳用时。界面沿用奶油色、鼠尾草绿、圆角面板与橘色点缀；小熊猫林地插画由已配置的第三方 API 使用 `gpt-image-2.5` 生成，提示词保存在 `tools/minesweeper-art.txt`。

## 规则与调整

核心规则参考 `D:/code/模型计算/兑换码分发/src/lib/minesweeper-engine.ts`：

| 难度 | 林地 | 棋盘 | 地雷 |
| --- | --- | --- | --- |
| easy | 林间小径 | 9 × 9 | 10 |
| normal | 深林营地 | 12 × 12 | 24 |
| hard | 雾中山谷 | 16 × 16 | 40 |

- 首次揭格和相邻八格均安全，空白自动连锁展开；点已揭开的数字可快速展开相邻格，前提是周围旗帜数与数字相等。误标仍可能触雷。
- 揭完全部安全格即获胜，不要求逐个插旗；失败后展示地雷和误标旗帜。
- 自由探索采用随机雷区，从首次揭格计时，主动暂停会停表并遮住棋盘。页面离开期间会继续计时，需停表时先点击暂停。
- 每日挑战按北京时间日期与难度生成固定雷区，自动揭开中心起点。开始即计时，暂停、离开和刷新均计时；同一天同难度的所有玩家面对相同棋盘。
- 原兑换平台的积分余额、积分奖励、每日收益上限和开局冷却不再适用，改为随时开局、探索得分和最佳用时。得分仅作本次游戏手记。
- 电脑左键探索、右键插旗；手机轻点探索、长按 450ms 插旗，或用插旗工具。较大的棋盘保留可读格子大小并可横向滑动。
- `F` 切换工具，空格暂停/继续，方向键移动棋盘焦点，Enter 操作当前格子。提供音效开关、全屏、规则弹窗和挑战/手记复制。

## 插件与账号接入

`createGameModule(context)` 通过 `mountMinesweeperRoutes(app, { auth: context.auth })` 挂载既有 `/api/minesweeper` 路由；保留 `AuthAdapter` 契约和游客模式。

现有账号模块的改动只有新增、导出 `minesweeperStatsOf(userId)`，其内部委托 `readMinesweeperStats(db, userId)`。迁移到 `auth.ts` 时可直接导入该 TS 查询函数。已有的 `recordMatch`、Cookie 身份解析与战绩表继续复用，无新增表或数据库迁移。

`AuthAdapter` 的四个可选方法：

- `parseCookies(header)`：已有 Cookie 解析；未提供时扫雷自行解析游客 Cookie。
- `userFromCookieHeader(header)`：已验证的账号身份。
- `recordMatch(match)`：已结束对局的战绩写入，返回记录 ID。
- `minesweeperStatsOf(userId)`：返回 `{ games, wins, bestTimes: { classic: {}, daily: {} } }`，各最佳用时按 `easy / normal / hard` 索引，单位毫秒。

战绩写入采用 `gameId: 'minesweeper'`、`mode: 'classic:easy'` / `'daily:normal'` 等标记，单人 `color: 0`，成功 `winnerColors: [0]`、失败 `[]`。只有服务端判定结束时写入，重复操作不会重复结算。游戏类型中文名已加到 `web/js/account.js`，游戏入口已加到 `web/games.json`。

## HTTP 接口

所有接口返回 JSON，并使用同源 Cookie 识别会话。状态响应只包含可见格子，不下发布雷种子、隐藏格数字或未结束局的雷位。

| 方法 | 路径 | 请求 / 返回 |
| --- | --- | --- |
| GET | `/api/minesweeper/status` | `{ date, difficulties, session, stats }` |
| POST | `/api/minesweeper/start` | `{ difficulty, mode, replaceSessionId? }` → `{ session }` |
| POST | `/api/minesweeper/action` | `{ sessionId, revision, requestId, action }` → `{ session, message }` |

格子操作为 `{ type: 'reveal' / 'flag' / 'chord', index }`，`index = row * cols + col`；暂停操作为 `{ type: 'pause' }` 或 `{ type: 'resume' }`。每次有效操作递增 `revision`，同一 `requestId` 的重试不重复执行。其他页面抢先更新时返回 409 与最新视图；前端同步后丢弃陈旧队列。

## 会话与当前交付状态

进行中的雷区保存在服务端内存，同一浏览器或同一账号可刷新续玩，24 小时无访问后过期；服务端重启会清空进行中的雷区。账号已完成战绩保存在现有 SQLite，本机手记保存在浏览器。游客在局中登录且该账号无现有雷区时，可把未完成探险接到账号上。

统一迁移的 Node 与 Playwright 测试覆盖首击保护、快速展开、幂等与版本冲突、暂停计时、每日同图、长按/拖动、刷新续玩、局中登录接回与账号结算，并在桌面、手机竖屏和横屏下检查页面资源与布局。
